# 电商图片提取下载

在淘宝 / 京东 / 拼多多商品详情页右下角显示「获取图片」按钮，点击后在 gallery 标签页集中展示所有商品图片，勾选后批量下载为 PNG。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`。
2. 右上角开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录（`imgDownload`）。

## 使用

1. 打开淘宝 / 天猫 / 京东 / 拼多多的商品详情页，右下角出现「获取图片」按钮。
2. 点击按钮，扩展会扫描页面图片（含懒加载与背景图），并自动打开 gallery 标签页。
3. 在 gallery 中勾选需要的图片（可「全选 / 反选」），点击「下载选中」。
4. 勾选的图片会统一转换为 PNG：勾选 1 张时直接保存为 `商品图_001.png`，勾选多张时打包为 `商品图.zip`（内含按序号命名的 PNG），保存到浏览器默认下载目录。

## 文件说明

- `manifest.json` —— MV3 配置与权限
- `content.js` / `content.css` —— 详情页按钮注入与图片收集
- `background.js` —— 消息转发与下载执行
- `gallery.html` / `gallery.js` / `gallery.css` —— 展示、勾选与转 PNG 下载
- `zip.js` —— 极简 ZIP 打包（多张下载时使用）

## 说明

- 转 PNG 仅在勾选并点击下载后执行，提取与预览阶段不转换。
- 若个别图片因防盗链等原因下载失败，会单独标记「失败」，不影响其余图片。
